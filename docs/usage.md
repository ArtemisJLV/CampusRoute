## 控制菜单

输入一个菜单数字并按回车。常用顺序为 **7 选择路线 → 8 设置参数 → 1 准备起点 → 2 开始移动**。

| 数字 | 操作 |
| --- | --- |
| **1** | 识别 USB 手机并准备起点；多台设备时提示选择 |
| **2** | 开始移动，或从暂停位置继续 |
| **3** | 暂停移动，持续保持当前位置 |
| **4** | 中止本次移动，持续保持当前位置 |
| **5** | 发送恢复真实定位指令，关闭设备连接 |
| **6** | 刷新累计距离、移动用时和当前状态 |
| **7** | 按编号选择内置或收藏路线；输入 `I` 导入 GPX／GeoJSON |
| **8** | 设置配速与目标公里数 |
| **9** | 打开地图，绘制自定义路线 |
| **10** | Android 后端：安装或更新配套 APK |
| **11** | 开关及设置配速波动、轨迹横向偏移 |
| **12** | 设置自定义路线是否默认保存为本地收藏 |
| **0** | 发送恢复真实定位指令，关闭地图服务并退出 |

修改路线和参数前，请先选择 **5** 断开连接。暂停后可以选择 **2** 继续；中止或达到目标后，开始新的一次移动需要先选择 **5**，再选择 **1**。

连接后控制台自动刷新距离、用时、手机已确认坐标及已发送速度／朝向。暂停或中止时立即发送零速度定位，收到回执后显示成功，之后持续保持该点。达到目标后保持终点，等待选择 **5** 或 **0**。

输入区域在状态刷新和窗口缩放期间保留正在输入的内容。左右方向键移动输入光标，Backspace 删除字符；输入数字后按回车执行操作。

Android 回执超时或无效时结束会话，显示错误与清理结果后返回菜单。保留路线与参数，按手机提示停止并恢复后，可以重新选择 **1** 连接。

## 配速与目标距离

菜单 **8** 使用 `分钟:秒` 格式，例如 `2:00`、`6:30`、`120:00`。最快为 **2:00／公里**，慢速没有人为上限；目标公里数可以为正数或小数，例如 `2.5`。首次启动默认为2:00配速、5公里。

配速、目标距离、路线选择、波动参数与保存开关会自动保存。下次启动恢复设置，移动进度重新开始。

## 自定义路线

### 在地图中绘制

1. 输入 **9** 打开地图。选择附近校区，或输入 `纬度,经度` 移动地图中心。
2. 选择 **四点足球场 → 自动生成跑道**，点击 **选取足球场四角**，沿球场边缘依次点选四个角。
3. 拖动蓝色角点修正位置，调整 **最小间距** 和 **弯道内收** 改变跑道大小。也可以切换 **逐点绘制路线**；绘制环形路线时点击 **闭合路线**。
4. 填写路线名称，点击 **完成路线**。默认加入收藏，页面显示新路线编号。
5. 回到终端，输入 **7**，再输入对应编号。需要文件副本时，在地图中点击 **下载 GeoJSON 副本**。

地图实时显示当前轨迹总距离；闭合路线显示单圈长度，开放路线显示单程长度。距离按 WGS84 椭球计算，与播放模块保持一致。

四点生成采用矩形足球场、两条直道与两段半圆的估算模型。最小间距表示球场边界到跑道的最近距离；弯道内收表示半圆圆心相对球门线向场内移动的距离，默认分别为2米与10米。该模型不能唯一还原真实跑道，也不强制生成400米；例如105×68米球场按默认参数生成的单圈约405米。下载文件保留四角与生成参数。

### 收藏与临时使用

自定义路线默认保存到 `user-routes/routes.geojson`，在内置路线之后按保存顺序分配数字编号。相同路线重复保存会复用已有选项，原导入文件移动或删除不影响收藏。

- 本次不保存：取消地图中的 **保存为路线选项，供下次使用**，路线仅在当前窗口提供编号。
- 关闭默认保存：终端输入 **12 → 2**；重新开启使用 **12 → 1**。地图页面需要重新加载才能采用新的默认值。

关闭保存开关会保留现有收藏。编辑内置路线时保留来源与数据许可；手动下载的路线文件由用户管理。

### 导入已有文件

输入 **7 → I**，按提示输入文件路径。路线至少10米，相邻坐标不能重复；GPX 时间与海拔不参与播放，速度由菜单配速决定。

| 格式 | 要求 |
| --- | --- |
| `.gpx` | 包含一条连续的 track segment 或 route |
| `.geojson` | 一个 `Feature`，几何为 `LineString`，坐标为 `[经度, 纬度]` |

```json
{
  "type": "Feature",
  "properties": {"name": "我的路线", "coordinate_system": "WGS84"},
  "geometry": {
    "type": "LineString",
    "coordinates": [[121.4992, 31.2821], [121.4998, 31.2817]]
  }
}
```

坐标必须使用 WGS84。高德 GCJ-02、百度 BD-09 坐标需要先转换；程序检查 `properties.coordinate_system` 声明，无法自动判断未标注坐标的来源。

## 配速与轨迹波动

菜单 **11** 默认关闭波动。输入 **1** 开启，依次设置配速波动百分比 **0—20** 与最大横向偏移 **0—3米**，回车采用当前值；初始幅度为 **±5%、0.6米**。幅度输入时 `0` 禁用该项，`Q` 取消。输入 **2** 关闭波动并保留幅度，下次连接生效。

开启后，配速与偏移缓慢变化，每次连接生成新的变化曲线。6:00配速、±5%对应5:42—6:18；最快仍不超过2:00／公里。横向偏移相对于原路线，程序不了解实际跑道边界，建议从0.6米等小幅度开始。

暂停、中止和到达目标时，位置与偏移冻结，速度为零；继续时接着暂停前的变化播放。累计距离按原路线的前进里程计算，横向偏移可能使目标应用统计的轨迹长度略有不同。

## 本地数据与隐私

| 内容 | 保存位置与方式 |
| --- | --- |
| 路线选择、配速、目标距离、波动与保存开关 | `work/settings.json` |
| 收藏路线的坐标与来源 | `user-routes/routes.geojson` |
| 未收藏路线、设备标识、会话令牌与移动进度 | 当前进程内存 |
| 程序运行日志与操作历史 | 不保存；错误直接显示在终端 |

`work/` 与 `user-routes/` 不提交到版本库。删除设置文件可恢复默认参数；删除路线收藏前，请先切换到内置路线。设置文件损坏时，程序停止启动并显示错误。

临时文件位于项目内 `work/.cache/`，正常退出时清理本次运行子目录。Python 环境、Android 构建产物与调试密钥、Apple 设备配对资料与开发者镜像供后续使用。ADB、Terminal、浏览器及操作系统自行管理缓存和记录。

地图服务仅监听 `127.0.0.1`。程序没有遥测、账号登录与数据上传功能。依赖安装及镜像准备会访问相应服务，地图底图会向 OpenStreetMap 请求当前区域的瓦片并显示署名。

## 结束使用与故障处理

正常结束请选择 **0**。Ctrl+C 与可处理的正常终止信号会触发设备清理；强制结束进程、关闭窗口或断电可能无法完成清理。Android 可点击手机或通知中的 **停止并恢复**；iPhone 可重新连接后执行菜单 **1、5**，必要时重启手机。

| 现象 | 查看或操作 |
| --- | --- |
| 安装失败、版本不一致 | [iPhone 环境升级与修复](iphone.md#更新与修复)／[Android 安装说明](android.md) |
| 找不到手机或无法准备起点 | [iPhone 连接说明](iphone.md#连接与恢复)／[Android 常见问题](android.md#常见问题) |
| 达到目标后仍停留在模拟位置 | 选择 **5** 恢复定位，或选择 **0** 退出 |
| 地图显示、距离或有效状态不符合预期 | 在目标应用中核查定位来源与统计规则；接口回执不代表目标应用已经采用该位置 |
